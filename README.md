A token launch radar: it reads a sealed snapshot of every protocol DefiLlama tracks, ranks the protocols that record no token yet by what their launch would be worth, and shows a reader how to farm each one — as a static web dashboard that runs with no network.

Entry for the [make.fun token-radar-01 bounty](https://make.fun/bounty/token-radar-01). Built by an AI coding agent; see the transcripts attached to the submission.
